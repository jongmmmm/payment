ABSTRACT · 논문 초록
연구 요약

글로벌 B2B 무역결제 시장에서 스테이블코인(Stablecoin)을 활용한 결제 비중은 전체의 약 40%에 달하며 연간 65%씩 급성장하고 있다. 한국 전체 무역의 약 10%가 이미 USDT 등 주요 스테이블코인을 통해 결제되고 있으나, 발행사의 건전성을 실시간으로 평가할 전용 시스템은 전무한 상태다. 기존 준비금 보고서는 평균 30~45일의 시차가 있어 2022년 FTX·테라루나 붕괴 같은 급격한 위기에 선제 대응이 불가능하다. 2023년 한 해에만 전 세계적으로 609건의 디페깅(De-pegging) 이벤트가 관찰되었으며, 이는 B2B 무역 기업에게 직접적인 환차손 및 자산 소실 위협이 되고 있다.


본 연구는 이를 해결하기 위해 가격 이탈(PD), 유동성 스트레스(LS), 담보비율(CR), 투명성 지수(TI), 규제 리스크(RR)의 5개 지표를 Ridge Regression 최적 가중합으로 통합한 SRHS(Stablecoin Real-time Health Score) 모델을 설계하였다. 모델은 20초 단위로 재연산되며, 위험 임계치 76점 도달 시 대체 자산으로의 즉각적인 스왑(Swap)을 권고하여 기업의 환차손 방어 의사결정을 수 초 내로 단축시킨다. 실시간 API(CoinGecko, DeFiLlama)를 활용하여 USDC·DAI·PYUSD·USDT 4종을 대상으로 모델 거동 검증 실험을 수행하였다.


실험 결과, 5가지 가중치 시나리오(A0~A4) 하에서 Spearman 순위 상관계수 ρ ≥ 0.80을 기록하여 모델의 강건성(Robustness)이 확인되었다. 민감도 분석에서는 4종 모두 LS 지표가 ±11~12점으로 최대 변동성을 나타내어, Z-score 기반 유동성 스트레스 측정이 패닉셀 전조 감지의 핵심 축임이 확인되었다. 현시점 USDT는 CR·TI·RR 3개 지표 동시 약세로 CAUTION(30.1점) 등급을 기록하였으며, 나머지 3종은 LOW 등급으로 안전이 확인되었다.

본 보고서에 등장하는 통계·금융·규제 용어를 쉽게 풀어쓴 참고 사전
Z-score (Z점수)
"오늘이 평소 대비 얼마나 이상한가"를 숫자로 표현. Z=0은 평균, Z=2는 평균에서 2배 표준편차 벗어남. 통계적으로 Z>3은 발생 확률 0.3% 미만 → 사실상 비정상 사태.
σ (시그마 / 표준편차)
데이터가 평균 주위에 얼마나 퍼져 있는지를 나타내는 단위. ±1σ = 평균 ±1배 표준편차. "2σ 충격"은 평균보다 2배 표준편차만큼 크거나 작은 극단값을 입력했다는 뜻.
VWAP (거래량 가중 평균가)
Volume-Weighted Average Price. 단순 평균가가 아니라 거래량이 많은 시점에 더 큰 비중을 줘서 계산한 가격. 거래 적은 시간대의 노이즈를 걸러내는 효과.
Ridge Regression (릿지 회귀)
데이터가 적을 때 과적합(overfitting)을 막는 선형 회귀 방법. L2 정규화(패널티)를 추가해서 특정 변수에 과도한 가중치가 몰리지 않도록 억제한다. SRHS는 이걸로 5개 지표 가중치를 딱 1번 도출 후 고정.
Spearman ρ (스피어만 상관계수)
두 결과의 순위가 얼마나 일치하는지 측정. ρ=1이면 순위 완전 일치, ρ=0이면 무관계. SRHS에서는 가중치를 바꿔도 코인 위험 순위가 유지되는지 검증하는 데 사용. ρ≥0.7이면 "강건"으로 판정.
디페그 (De-peg)
스테이블코인 가격이 기준값($1)에서 벗어나는 현상. 1%만 벗어나도 B2B 무역결제에서 수십억 원 환차손 발생 가능. SRHS는 0.5% 이탈부터 조기 경보를 발령한다.
뱅크런 (Bank Run)
많은 사람이 동시에 자산 인출을 요청하는 사태. 스테이블코인에선 "대규모 동시 상환 요청"을 뜻한다. 2022년 UST 붕괴가 대표적. SRHS LS 지표의 Z-score≥3이 뱅크런 시작 신호.
Anti-FTT 필터
발행사 자신의 토큰을 준비금 담보로 쓰는 구조를 차단하는 안전장치. FTX가 자사 토큰 FTT를 담보로 쓰다가 FTT 폭락과 함께 동시 붕괴. 이 구조가 감지되면 SRHS가 자동으로 CRITICAL 등급 강등.
Lead Time (리드 타임)
실제 디페그 발생 시각 − SRHS가 76점에 도달한 시각. 예: Lead Time = 3h → SRHS가 실제 붕괴보다 3시간 먼저 경보를 울렸다는 뜻. 클수록 선제 대응 시간이 길어진다.
MiCA · CARF · 외국환거래법
MiCA = EU 암호자산 규제법(2023). CARF = OECD 암호자산 세금 보고 체계(2027 발효). 외국환거래법 = 한국 외화 거래 사전신고 의무 법률. 세 규제 모두 스테이블코인 B2B 결제에 직접 적용된다.
99% CI (신뢰구간)
Confidence Interval. "100번 중 99번은 이 범위 안에 든다"는 통계적 확신 수준. SRHS 뱅크런 내성 테스트에서 99% CI 기준 최악의 상환 요청량을 가정하고 버틸 수 있는지 시뮬레이션한다.
Attestation (어테스테이션)
발행사가 "준비금이 실제로 있다"고 외부 감사법인이 확인해주는 보고서. 법적 감사(Audit)보다 낮은 수준. USDC는 월간, USDT는 분기 발행 — 발행 주기가 길수록 신뢰도 낮음.

📐 기호·표기 설명

ρ (로, rho)
Spearman 순위 상관계수. 두 순위가 얼마나 같은지를 -1~1로 표현. ρ=1.000 → 완전 일치, ρ=0.800 → 80% 수준으로 일치 (강건 기준 ≥0.7).
Δ (델타)
"변화량"을 뜻하는 기호. ΔSRHS = SRHS 점수의 변화량. 예: ΔSRHS = +11.03 → 충격 후 점수가 11.03점 상승.
σ (시그마) · ±1σ · ±2σ
표준편차 단위. ±1σ = 평균에서 1배 표준편차 범위 (데이터 약 68% 포함). ±2σ = 약 95% 포함. 민감도 분석에서 "±2σ 충격" = 극단적이지만 현실적인 충격 시나리오.
A0 · A1 · A2 · A3 · A4
가중치 시나리오 이름. A0 = 기준(베이스라인), A1~A4 = 가중치를 다르게 설정한 비교 시나리오. 결과가 비슷하면 → 모델이 가중치에 민감하지 않다(강건).
RQ1 · RQ2 · RQ3 · RQ4
Research Question(연구 질문) 번호. RQ1=강건성, RQ2=민감도, RQ3=백테스팅 선행 경보, RQ4=필터 효과. 각 실험이 어느 질문에 답하는지 추적하는 라벨.
≥ · ≤ · → · ≈
≥ = 이상(크거나 같음), ≤ = 이하(작거나 같음), → = 이면/결과, ≈ = 약 같음. 예: SRHS ≥ 76 → CRITICAL = "점수가 76 이상이면 CRITICAL 등급".
T · T-72h · T+24h
T = 기준 시각(보통 디페그 발생 시각). T-72h = T보다 72시간 전. T+24h = T보다 24시간 후. 백테스팅에서 이벤트 전후 구간을 표시하는 방식.
CI (신뢰구간) · 99% CI
Confidence Interval. 99% CI = "100번 시뮬레이션 중 99번은 이 범위 안에 든다"는 의미. 뱅크런 내성 테스트에서 최악의 1% 상황까지 버티는지 검증.
clip( x, 0, 3 )
x가 0보다 작으면 0으로, 3보다 크면 3으로 강제 고정하는 함수. 예: clip(-1, 0, 3) = 0, clip(5, 0, 3) = 3. 이상치가 점수에 과도한 영향을 주지 않도록 막는 장치.
FPR (False Positive Rate)
오탐율. 실제로 아무 이상 없는 정상 기간에 SRHS가 76점을 잘못 넘은 비율. FPR이 낮을수록 "불필요한 경보"가 적어 실무에서 신뢰도 높음.
L2 정규화 (Ridge 패널티)
Ridge Regression에서 가중치가 너무 커지지 않도록 억제하는 장치. 데이터가 적을 때 특정 변수에 가중치가 몰리는 과적합(overfitting)을 막는다.
PoR (Proof of Reserve)
준비금 증명. 블록체인 온체인에서 "이만큼의 준비금이 실제 지갑에 있다"는 것을 실시간으로 공개하는 방식. Attestation보다 더 투명한 수준.

1-1. 연구의 배경 — B2B 무역결제 시장의 구조적 취약성

글로벌 무역 및 거시 경제 환경에서 블록체인 기술 기반의 가상자산은 전통적인 금융 결제 시스템의 시공간적 제약과 높은 수수료 구조를 극복하는 대안으로 급부상하고 있다. 특히 법정화폐와의 가치 고정성을 특징으로 하는 스테이블코인(Stablecoin)은 환 변동 위험을 최소화하려는 무역 기업들의 수요와 결합하여 B2B 무역결제 시장의 지형을 급격하게 변화시키고 있다.

이처럼 스테이블코인을 활용한 무역 결제 시장이 급성장하고 있음에도 불구하고, 기업들이 마주한 실무적 리스크를 선제적으로 방어할 전용 신용평가 시스템은 전무한 상태다. 가장 치명적인 문제는 발행사들이 공시하는 오프체인 준비금 보고서(Reserve Reporting)의 심각한 시차다. 현재 주요 발행사들의 준비금 보고는 평균 30~45일 지연되어 발표되므로, 초 단위로 급변하는 가상자산 시장의 유동성 위기나 자산 부실화를 사전에 감지하는 것이 구조적으로 불가능하다.

한국 기업의 외국환거래법(外國換去來法) 컴플라이언스 리스크:
한국 기업이 스테이블코인으로 무역대금을 결제할 때, 현행 외국환거래법상 한국은행 총재에게 사전 신고·수리를 받아야 하는 절차가 필수적이다. 그러나 블록체인 온체인 트랜잭션을 통한 무역대금 결제에 대한 명확한 세부 시행령이나 전용 행정 경로가 부재하여, 기업들이 미신고 지급 위반으로 인한 형사 처벌·과태료 리스크에 상시 노출되어 있다. 본 모델의 RR(규제 리스크) 지표는 이 국내법적 리스크를 정량화하여 반영한다.

1-2. 역사적 위기 사례 — 실시간 복합 지표의 필요성 실증

아래 4가지 사례는 복합 위험 지표 모니터링 시스템의 필요성을 직접 증명한다.

2022년 11월 · FTX 붕괴

자기참조 담보(Self-referential Collateral)의 실패

FTX는 자사 발행 토큰 FTT를 담보로 사용했다. FTT 가격이 하락하자 담보 가치가 동시에 증발하며 72시간 안에 320억 달러가 소멸했다. 담보비율(CR)이 실시간으로 모니터링되었다면 자기참조 구조를 사전에 포착할 수 있었다.

2022년 5월 · 테라루나(UST) 붕괴

알고리즘 무담보 구조의 한계

UST는 담보 없이 알고리즘으로만 가치를 유지했다. 디페그 76시간 전부터 거래량(LS) 폭증 신호가 있었으나 자동 경보 시스템이 없었다. 결과적으로 48시간 만에 400억 달러가 소멸했다.

2023년 3월 · USDC SVB 사태

피아트 담보도 위험하다 — 준비금 위치의 문제

Circle이 SVB(실리콘밸리 은행)에 예치한 33억 달러가 SVB 파산으로 동결되면서 USDC가 $0.87까지 디페그됐다. 발행사 준비금의 예치 기관(TI 지표)을 추적하지 않으면 이런 위험은 사전에 보이지 않는다.

2024년 · EU MiCA 규정 시행

규제가 정량 위험 지표를 요구하기 시작했다

EU MiCA(Markets in Crypto-Assets) 규정은 스테이블코인 발행사에 실시간 준비금 공시, EMT 인가, 유동성 기준을 의무화했다. 단순 가격 모니터링이 아닌 복합 정량 지표가 제도적으로도 필요해졌다.

SRHS가 필요한 이유 — 기존 시스템의 한계와 학술적·실무적 공백

  • 기존 시스템(Webacy, Moody's 등)은 개인 투자자 중심 보안 또는 거시적 신용평가 — B2B 무역결제·외국환거래법·CARF 통합 모델 전무
  • 가격 이탈(PD)만 보면 테라루나 초기 76시간 동안 정상으로 보임 → 5개 지표 동시 측정이 필수
  • USDT·PYUSD의 거래량은 절대 수치로 700배 차이 → Z-score 정규화 없이는 공정한 비교 불가
  • 임의 가중치 모델은 학술 신뢰도 없음 → Ridge Regression으로 역사적 사건(FTX·테라루나) 기반 가중치 1회 최적화
  • 디페그 발생 후 대응은 이미 늦음 → 20초 주기 재연산 + 76점 임계치 자동 스왑 권고로 선제 대응
  • 단순 기술 지표로는 한국 무역 기업의 법적 리스크 해소 불가 → 외국환거래법·MiCA·CARF를 RR 지표에 직접 매핑하여 컴플라이언스 위험 정량화
SECTION 02
실험 설계 개요
무엇을 어떻게 검증하는가? — RQ1~RQ4 및 시나리오 A0~A6
실험의 성격: 이 실험은 독립변수가 종속변수에 미치는 인과관계를 증명하는 것이 아닙니다. SRHS 모델 자체의 거동(behavior)을 확인하는 실험적 테스트입니다 — 가중치가 달라질 때 점수와 순위가 일관되는지(강건성), 어떤 지표에 가장 민감한지(민감도), 과거 사건에서 미리 경보를 울렸는지(선행성)를 측정합니다.

연구 질문 (Research Questions)

RQ1 · ROBUSTNESS

가중치를 바꿔도 순위가 유지되는가?

베이스라인(A0) 대비 A1~A4로 가중치를 변경할 때, 4종 자산의 위험 순위가 뒤집히지 않는가? 이것이 "강건성"의 정의입니다.

측정: Spearman ρ ≥ 0.7이면 강건 판정
RQ2 · SENSITIVITY

어떤 지표가 점수를 가장 많이 흔드는가?

5개 지표 중 하나에 ±1σ, ±2σ 충격을 가할 때 SRHS 변화량(ΔSRHS)이 가장 큰 지표는 무엇인가?

측정: 토네이도 차트, ΔSRHS/Δσ
RQ3 · BACKTESTING

과거 디페그 이전에 76점을 넘었는가?

2022 UST 붕괴, 2023 USDC SVB 사태에서 SRHS가 실제 디페그 몇 시간 전에 임계치 76점을 통과했는가? (Lead Time 측정)

측정: Lead Time(시간), FPR
RQ4 · FILTER ABLATION

필터를 끄면 등급이 어떻게 달라지는가?

A5(Anti-FTT 비활성)·A6(루나 필터 비활성) 시나리오에서 A0 대비 등급이 어떻게 달라지는가? (Ablation Study)

측정: 등급 변화 자산 수, 점수 차이
★ RQ ↔ 실험 방법 한눈 정리 — "7개 시나리오가 4개 질문을 전부 답하는 게 아닙니다"

SECTION 03
데이터 소스 및 수집 방법
어떤 데이터를, 어디서, 어떻게 가져왔는가?

SRHS 모델은 실시간성과 신뢰성을 동시에 확보하기 위해 멀티소스 컨센서스 방식을 채택한다. 동일 지표를 2개 이상 소스에서 수집하며, 소스 간 값이 50% 이상 이탈하면 이상치로 제거한다. 분석 기간은 2022-01 ~ 2026-04이며, 현재값 검증은 CoinGecko 실시간 API 기준이다.

🦎

CoinGecko API (실시간 · 주요 소스)

무료 공개 REST API. 1분 단위 갱신. 4종 코인(usd-coin, dai, paypal-usd, tether)의 시세·거래량·유통량을 수집한다. Python requests로 호출, 429 응답 시 8초 대기 후 재시도.

현재가 (price_usd) 24h 거래량 유통량 (supply) 30일 거래량 히스토리

→ PD(가격이탈), LS(유동성 Z-score) 계산에 사용

🦙

DeFiLlama API (온체인 담보 데이터)

DeFi 프로토콜 TVL 전문 데이터베이스. MakerDAO(DAI) 프로토콜의 온체인 담보 자산 총가치(TVL)를 실시간 제공한다. DAI의 CR(담보비율)은 TVL / DAI 유통량으로 산출한다.

MakerDAO TVL 온체인 PoR 담보 구성 비율

→ DAI CR 계산에 사용 (피아트 코인은 Attestation 기반)

📋

발행사 Attestation 보고서 (분기 고정값)

Circle(USDC), Tether(USDT), Paxos(PYUSD)의 공식 준비금 보고서에서 수집한 담보비율. 월간 또는 분기 발행. 이 값은 보고서 갱신 시 수동 업데이트한다.

USDC CR: 92% USDT CR: 62% PYUSD CR: 78% 감사기관 독립성

→ CR(피아트 코인), TI(투명성) 계산에 사용

⚖️

규제 기준 정성 평가 (전문가 고정값)

EU MiCA 전자화폐토큰(EMT) 인가 요건, CARF 가입 여부, FATCA·외국환거래법 준수 여부를 기반으로 전문가가 정성 평가 후 점수를 고정 부여한다. 분기마다 검토 및 갱신.

MiCA EMT 적합 여부 CARF 가입 공시 주기 (월/분기) 규제 관할권

→ TI(투명성), RR(규제 위험) 계산에 사용

왜 TI·RR은 실시간이 아닌 고정값인가?
발행사의 공시 구조(월간 감사 vs 분기 요약)나 규제 관할(미국 vs 홍콩 vs EU)은 수개월 단위로 변한다. 하루 이틀 단위로 실시간 측정을 시도하면 오히려 노이즈가 발생한다. MiCA EMT 기준, CARF 가입 여부를 기반으로 전문가 정성 평가 후 고정값으로 부여하는 것이 더 신뢰성 있는 방법이다. USDT RR=55점은 홍콩 소재 + CARF 미가입 + 분기 attestation에서 도출된 수치다.
SECTION 04
알고리즘 선택 근거
왜 딥러닝·ML이 아닌가? Ridge Regression을 선택한 이유는?

4-1. 핵심 질문: "이게 머신러닝·딥러닝인가요?"

아닙니다. SRHS는 딥러닝·머신러닝으로 가중치를 반복 학습하는 모델이 아닙니다.

정확한 설명: FTX 붕괴·테라루나 붕괴라는 역사적 사건 2개를 기반으로 Ridge Regression(선형 회귀의 일종)을 단 1회 실행해서 가중치를 도출했습니다. 이후 가중치는 고정됩니다 — 실시간으로 바뀌거나 학습하지 않습니다.
실행될 때마다 가중치가 갱신되는 신경망(Neural Network), 반복 학습하는 Random Forest와 완전히 다른 구조입니다. 정확한 분류: 해석 가능한(Explainable) 규칙 기반 복합 지수 모델 + 1회성 Ridge 가중치 최적화.

방법론 비교표 — SRHS가 다른 방법을 선택하지 않은 이유

표 3. 후보 방법론 비교 및 SRHS 선택 근거
방법론 작동 원리 우리 사례 적합성 선택?
Ridge Regression
★ 선택		 선형 회귀 + L2 정규화. 과거 사건(FTX·테라루나)을 역산해 지표별 가중치를 단 1회 도출. 이후 고정. 사건 데이터 2건 뿐 → 과적합 방지 필수 → L2 정규화(Ridge)가 정확히 이 문제를 해결. 해석 가능한 숫자 가중치 제공. 선택
단순 가중합
(기존 방식)		 연구자가 임의로 가중치 설정 (예: 모두 20%). 근거 없는 가중치 → 교수 지적: "가중치 설정 근거 필수". CR이 왜 25%인지 설명 불가. 학술 신뢰도 낮음. 미선택
Logistic Regression
(분류 ML)		 입력값 → 0/1 이진 분류. 충분한 레이블 데이터(위험/안전 사례) 필요. 스테이블코인 디페그 사건은 역사상 10건 미만 → 레이블 데이터 절대 부족. 데이터 불균형 심각. 미선택
Random Forest · XGBoost
(앙상블 ML)		 수백 개 결정 트리로 비선형 패턴 학습. 수만 건 이상 학습 데이터 필요. 학습 데이터 절대 부족(10건 미만) → 과적합 불가피. 결과 해석도 어려워 금융 규제 보고에 부적합. 미선택
LSTM · Transformer
(딥러닝)		 시계열 패턴을 다층 신경망으로 학습. 수십만 건 이상 데이터 + 강력한 GPU 필요. 데이터 부족 + "왜 이 점수가 나왔는지" 설명 불가(블랙박스). 금융 규제 환경에서 해석 가능성은 비선택 이유 1순위. 미선택
AHP (계층적 분석)
(전문가 판단)		 전문가 쌍대비교 행렬로 지표 간 중요도 도출. 전문가 편향 가능성, 재현성 낮음, 역사적 사건 데이터를 활용하지 못함. 미선택
Ridge Regression을 선택한 핵심 이유 3가지:
① 데이터 제약 — 주요 디페그 사건이 2건 뿐 → 복잡한 모델은 과적합 필연적 → Ridge의 L2 정규화로 해결
② 해석 가능성(Explainability) — "CR이 25%인 이유는 담보 붕괴가 가장 치명적이었기 때문"이라고 설명 가능
③ 규제 적합성 — 금융 규제 환경에서 블랙박스 모델은 심사 통과 어려움. Ridge는 투명한 숫자 가중치 제공
Q. 보통 머신러닝은 반복 학습하지 않나요? — SRHS는 왜 1회만 실행했나요?
구분 신경망·Random Forest (반복 학습) SRHS (Ridge 1회 최적화)
학습 방식 수천~수만 번 반복 업데이트 (epoch) 단 1회 수식 풀기 (수학적 최솟값 직접 계산)
가중치 상태 실행·데이터마다 계속 갱신됨 도출 후 고정 — 실시간으로 절대 바뀌지 않음
필요 데이터 수백~수천 건의 라벨링된 사례 FTX 1건 + 테라루나 1건 = 2건으로 충분
해석 가능성 블랙박스 — "왜 이 점수?" 설명 어려움 투명한 숫자 가중치 — "CR 25%는 담보 붕괴가 치명적이었기 때문"
규제 적합성 금융 규제 심사에서 설명 요구 대응 어려움 MiCA·CARF 기준과 1:1 매핑 가능
핵심 답변: 스테이블코인 붕괴 사건은 역사상 손에 꼽힐 만큼 드뭅니다. FTX·테라루나처럼 실제 데이터로 쓸 수 있는 사례가 2건뿐인 상황에서 신경망을 돌리면 데이터 2개로 수만 개의 파라미터를 학습하는 셈 → 극단적 과적합 발생. Ridge Regression은 수학적으로 최적해를 한 번에 구하면서 L2 패널티로 과적합을 억제합니다. 결과로 나온 가중치 5개(합계 100%)는 이후 완전 고정 — SRHS가 실시간으로 점수를 계산할 때마다 이 고정 가중치에 그날의 실시간 지표값을 곱해 더할 뿐입니다.

한 문장 정리: "SRHS는 가중치를 한 번 역사적 사건으로 교정하고, 이후 실시간 지표를 고정 공식에 대입하는 해석 가능한 규칙 기반 지수(Explainable Rule-Based Index)입니다."

4-2. Ridge Regression 가중치 도출 과정 및 결과

베이스라인 가중치(A0)는 FTX·테라루나 붕괴 사례를 역산 데이터로 사용한 Ridge Regression을 통해 도출되었다. 각 사건에서 최종 디페그/붕괴 결과를 종속변수(y), 5개 지표의 사후 역산값을 독립변수(X)로 설정하여 L2 정규화 선형 회귀를 1회 수행하였다.

// ══ SRHS 최종 계산 공식 (베이스라인 A0) ══
SRHS = PD×0.20 + LS×0.20 + CR×0.25 + TI×0.20 + RR×0.15

// ══ 각 지표 계산 알고리즘 ══
PD = min( |price - 1| / 0.02 × 100, 100 ) // 2% 이탈 = 만점 100
LS = clip( Z-score(vol_today, vols30d), 0, 3 ) / 3.0 × 100 // 30일 평균·표준편차 기반 정규화
CR = max( 0, 100 - min(cr_ratio × 100, 200) ) // 역선형: 높은 담보 = 낮은 위험 점수
TI = 100 - ti_qualitative_score // MiCA 기준 정성평가 역산
RR = rr_qualitative_score // CARF·외국환법 기준 정성평가

// ══ 등급 분류 기준 ══
SRHS ≤ 30 → LOW (안전)
SRHS ≤ 55 → CAUTION (주의)
SRHS ≤ 75 → HIGH (위험)
SRHS > 75 → CRITICAL (즉시 교체)

4-3. 지표별 알고리즘 — 기존 방식과 SRHS 비교

📊 PD — 가격 이탈 점수

❌ 기존: (price - 1) × 100 단순 퍼센트
✅ SRHS: |price - 1| / 0.02 × 100 선형 정규화 (상한 100점)
왜 바꿨나? 기존은 2% 이탈이 2점으로 너무 민감도가 낮다. SRHS는 2% 이탈 = 만점 100점이 되도록 감도를 극대화. 절댓값을 쓰는 이유: $1보다 높아도 낮아도 모두 위험 신호다.

▶ VWAP 기반 실시간 모니터링: 단순 현재가 대신 VWAP(거래량 가중 평균가)를 기준가로 사용한다. 거래량이 적은 시간대에 일시적으로 발생하는 스팟 가격 노이즈를 필터링하여 실제 시장 가격 형성 중심을 정확히 추적한다.

▶ 0.5% 조기 경보 임계치: PD ≥ 0.5% (점수 25점) 도달 시 즉시 조기 경보를 발령한다. 테라루나식 구조적 붕괴는 대규모 이탈이 발생하기 수 시간 전부터 0.5~1%대 소규모 이탈 신호가 선행한다 — 이 초동 징후를 기존 방식은 0.5점으로 무시하지만 SRHS는 25점으로 즉시 포착한다.

📈 LS — 유동성 스트레스 점수

❌ 기존: 거래량 절대값 직접 비교
✅ SRHS: Z-score 기반 + 상한 3σ 클리핑 (30일 롤링 윈도우)
왜 바꿨나? USDT 하루 거래량 500억 달러 vs PYUSD 7천만 달러. 절대값 비교하면 PYUSD는 항상 "정상"으로 나온다. Z-score는 각 코인 자신의 30일 평균 대비 오늘이 얼마나 이상한지를 측정. 유통량 규모 편향 없이 공정하게 패닉셀 전조를 탐지한다.

▶ 3-Sigma 법칙 (뱅크런 확정 신호): Z-score ≥ 3.0이면 LS = 100점(만점)으로 강제 클리핑한다. 통계적으로 정규분포에서 Z > 3.0은 발생 확률 0.3% 미만 — 이는 단순 거래량 급증이 아니라 패닉셀(panic sell) 또는 뱅크런(bank run)이 이미 진행 중임을 의미한다. 테라루나 붕괴 76시간 전 Z-score는 4.2를 기록하며 이 임계치를 초과했다.

▶ SNS 연동(SS — Social Stress): 소셜미디어 언급량 급증(±2σ 초과) 시 LS 점수에 가중 승수(multiplier)를 적용하여 심리적 패닉 리스크를 추가 반영한다. 시장 심리 지표를 정량 수치로 통합하는 구조다.

🏦 CR — 준비금 부족 점수

❌ 기존: 준비금 비율 그대로 사용 (높으면 높은 점수)
✅ SRHS: max(0, 100 − min(CR비율×100, 200)) 역선형
왜 바꿨나? 준비금이 높을수록 위험이 낮아야 하는데 그대로 쓰면 반대로 표현된다. 역선형으로 100% 담보 = 0점(완전 안전), 0% 담보 = 100점(최고 위험). DAI처럼 200% 초과 과담보는 0점 클리핑 — 과도한 안전 과소평가 방지.

▶ Anti-FTT 필터 (자기참조 담보 차단): 준비금 내 발행사 유관 토큰(issuer-related token)이 5%를 초과하면 CR을 즉시 CRITICAL 등급으로 강제 강등한다. FTX는 자사 토큰 FTT를 담보로 사용했으며, FTT 가격 폭락과 동시에 담보 가치가 연쇄 붕괴했다 — Anti-FTT 필터는 이 자기참조 담보의 위험을 사전 차단한다.

▶ 루나 필터 (SM 강제 최하위): 단일 생태계 100% 의존 또는 알고리즘 자율조정 구조(무담보 민팅/버닝)인 경우, Stability Mechanism(SM) 점수를 강제로 최하위로 고정한다. 2022년 UST는 LUNA 토큰과 알고리즘으로만 페그를 유지하다가 뱅크런 한 번에 1,000억 달러가 소멸했다 — 루나 필터는 이 구조를 원천 차단한다.

📋 TI / RR — 투명성·규제 점수

❌ 기존: 실시간 측정 없음 또는 단순 분류
✅ SRHS: MiCA·CARF·외국환거래법 기준 정성 평가 고정값 (분기 갱신)
왜 고정값인가? 규제 관할·공시 구조는 수개월 단위로 변한다. 실시간 측정 시 노이즈 발생. 전문가 정성 평가 후 점수화하여 분기마다 검토·갱신한다.

▶ TI (투명성) 채점 기준:
  • 공시 주기: 주간 Attestation = 100점, 월간 = 70점, 분기 = 40점
  • 수탁기관 독립성: 발행사와 법적 독립된 제3자 수탁 = +10점 가산
  • 감사법인: Big4(Deloitte·PwC·EY·KPMG) 감사 = +10점 가산
  • 온체인 PoR(Proof of Reserve): 실시간 온체인 공개 = +15점 가산
USDC: 월간 attestation + Big4(Deloitte) + 독립 수탁 → TI 원점수 낮음(안전).
USDT: 분기 attestation + Big4 미적용 + 발행사 자체 수탁 → TI 원점수 높음(위험).

▶ RR (규제 위험) 채점 기준: MiCA EMT/ART 적합 여부, CARF(OECD 암호자산 보고체계) 가입국 여부, 한국 외국환거래법 사전신고 면제 해당 여부를 종합 평가한다. USDT RR=55점: 홍콩 소재(외국환법 위험) + CARF 미가입 + MiCA 미적합 논란에서 도출. USDC RR=14점: 미국 규제 준수 + MiCA EMT 적합 심사 중 + CARF 가입국에서 도출.

4-EX-1. SS (Social Stress) — 소셜 리스크 지표

SRHS 5개 핵심 지표는 온체인·시장 데이터 기반이다. 그러나 암호화폐 시장에서 심리적 패닉(psychological panic)은 온체인 신호보다 SNS 반응이 선행하는 경우가 많다. 2023년 3월 USDC의 SVB 관련 디페그는 실제 준비금 문제 발생 전 Twitter/X 상의 루머 확산이 선행했다. SS 지표는 이 소셜 선행 신호를 정량화하여 LS 지표에 반영한다.

// ══ SS (Social Stress) 알고리즘 ══
SS_raw = Z-score( SNS_mention_volume_today, SNS_mentions_30d ) // SNS 언급량 Z-score
SS_theme = Z-score( theme_asset_volatility_today, vol_30d ) // 연관 테마 자산 변동성 Z-score
SS = clip( max(SS_raw, SS_theme), 0, 3 ) / 3.0 × 100 // 3σ 클리핑 정규화

// ══ LS 최종값에 SS 승수 적용 ══
LS_adj = LS_base × (1 + 0.15 × SS / 100) // SS가 최대일 때 LS 15% 증폭
// SS ≥ 2σ 초과 시 조기 경보 플래그 별도 발령
수식 2. Social Stress(SS) 알고리즘 — SNS 패닉 신호를 LS 승수로 통합
설계 근거: 시장 심리는 온체인 데이터보다 최대 4~6시간 선행하는 경우가 관측된다 (USDC SVB 사례: Twitter 루머 발생 → 디페그까지 약 5시간). SS가 LS에 승수로 작용하면 순수 거래량 이상 감지에 심리 가속 요인이 더해져 패닉 국면에서의 리드 타임(Lead Time)을 추가 확보할 수 있다. 단, SS는 독립 지표가 아닌 LS 보조 변수로 설계하여 가중치 5개의 합이 100%를 유지하도록 한다.

4-EX-2. 뱅크런 내성 테스트 (99% CI Resilience Test)

준비금 비율 CR만으로는 "지금 당장 대규모 상환 요청이 오면 버틸 수 있는가"를 알 수 없다. SRHS는 CR 보완 지표로 99% 신뢰구간 기반 뱅크런 내성 시뮬레이션을 수행한다.

4-EX-3. 자동 스왑 알고리즘 — SRHS 76점 트리거

B2B 무역결제에서 기업 담당자가 스테이블코인 위험을 인지하고 대체 자산으로 교체하기까지 기존에는 수 시간에서 수십 시간이 소요되었다. SRHS는 76점 임계치 도달 시 즉시 스왑 권고를 생성하여 의사결정 시간을 수 시간에서 약 20초 이내로 단축한다.

// ══ 자동 스왑 트리거 알고리즘 ══
IF SRHS(asset_current) ≥ 76 // CRITICAL 임계치 초과
THEN:
1. 즉시 알림 발령 (Push / Dashboard 경보)
2. 대체 자산 후보 목록 생성:
candidates = [ a for a in assets if SRHS(a) < 30 ] // LOW 등급만
candidates.sort( key = lambda a: SRHS(a) ) // 점수 낮은 순 정렬
3. swap_recommendation = candidates[0] // 가장 안전한 자산 추천
4. 20초 재연산 후 지속 모니터링

// ══ Lead Time 측정 (RQ3) ══
Lead_Time = T_depeg_actual − T_SRHS_76_first_hit // 단위: 시간(h)
// 목표: Lead_Time ≥ 1h (최소 1시간 선행 경보)
수식 3. 자동 스왑 트리거 알고리즘 — SRHS 76점 도달 시 즉시 교체 권고 생성

종합 결론

현시점 4종 스테이블코인 중 CRITICAL(즉시 교체)은 없으며, USDT만 CAUTION(30.1점)이다.
5가지 가중치 시나리오에서 Spearman ρ ≥ 0.8로 모델의 강건성이 실험적으로 검증되었다.
LS(유동성 스트레스) 지표가 ±11~12점으로 점수 변동에 가장 민감하여, Z-score 기반 LS 설계가 패닉셀 조기 감지의 핵심 축임이 확인되었다.
SRHS는 딥러닝·머신러닝이 아닌 Ridge Regression 1회 가중치 최적화 기반의 해석 가능한 규칙 기반 복합 지수 모델로서, 금융 규제 환경에서 요구되는 투명성과 설명 가능성을 갖추었다.
